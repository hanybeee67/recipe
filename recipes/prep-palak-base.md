## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 시금치 | 1,000g |  |
| 2 | CUMIN seed powder | 100g |  |
| 3 | 꽃소금 | 30g |  |
| 4 | 통마늘 | 100g |  |
| 5 | 통생강 | 50g |  |
| 6 | 청양고추 | 30g |  |

## 조리 방법

1. 시금치를 다듬어 흐르는 물에 깨끗이 씻는다.
2. 끓는 물에 시금치를 30초~1분간 데친 뒤 즉시 얼음물에 담가 색을 고정한다.
3. 물기를 두 손으로 꼭 짜낸다. 수율 80%는 이 단계에서 나온다.
4. 통마늘, 통생강, 청양고추를 굵게 썬다.
5. 데친 시금치, 마늘, 생강, 청양고추, 커민 파우더, 꽃소금을 블렌더에 넣고 곱게 간다.
6. 완전히 식혀 냉장 보관하고 2~3일 안에 쓴다. 오래 두면 색이 갈변한다.
