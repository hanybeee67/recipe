## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 퍼니르 (치즈) | 50g | 깍뚝썰기 |
| 2 | 커리 그레이비 소스 | 130g |  |
| 3 | ASEEL PURE GHEE (버터) | 5g |  |
| 4 | 토마토 | 5g | 다지기 |
| 5 | 설탕 | 20g | 단맛 조절 |
| 6 | 데어리쿠킹크림 | 20g |  |
| 7 | 꽃소금 | 15g |  |

## 조리 방법

1. ASEEL GHEE를 팬에 녹이고 퍼니르를 넣어 황금빛이 될 때까지 겉면을 굽는다.
2. 같은 팬에 다진 토마토를 넣어 1분간 볶는다.
3. 커리 그레이비 소스와 설탕을 넣어 잘 섞는다.
4. 구운 퍼니르를 넣고 약불로 3~4분간 조린다.
5. 데어리쿠킹크림을 넣어 크리미하게 완성하고 소금으로 간한다.
6. 버터 한 조각을 올려 서빙한다.

## 가니쉬

완성된 커리 위에 생크림. 체리 1개와 고수잎 장식.
