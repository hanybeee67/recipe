## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭 (부위 정육) | 300g | 곱게 다지기 |
| 2 | CUMIN powder | 5g |  |
| 3 | 치킨 마살라 파우더 | 5g |  |
| 4 | 베트남 고추가루 | 10g |  |
| 5 | 꽃소금 | 5g |  |
| 6 | 식용유 | 5g |  |
| 7 | 탄두리 소스 | 10g | 마리네이드 |
| 8 | 청양고추 | 30g | 서빙용 |
| 9 | 마요네즈 소스 | 30g |  |

## 조리 방법

1. 닭 다짐육에 커민가루, 마살라, 고추가루, 소금, 탄두리 소스를 넣어 골고루 섞는다.
2. 반죽을 꼬치에 소시지 모양으로 붙여가며 성형한다.
3. 탄두리 오븐에서 12~15분간 굽는다.
4. 중간에 한 번 뒤집고 식용유를 살짝 바른다.
5. 고소한 향이 나고 겉면이 노릇해지면 꺼내 서빙한다.

## 가니쉬

케밥을 사선으로 배치. 민트 처트니, 레몬 웨지, 양파 링 곁들임.
