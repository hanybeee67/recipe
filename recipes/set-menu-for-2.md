## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 치킨 커리 또는 베지 커리 | 1개 | 메인 커리 선택 |
| 2 | 머턴 커리 또는 달 머커니 | 1개 | 메인 커리 선택 |
| 3 | 플레인 난 | 2개 |  |
| 4 | 밥 (바스마티 라이스) | 2인분 |  |
| 5 | 그린 샐러드 | 1개 |  |
| 6 | 더히 (요거트) | 1개 |  |

## 조리 방법

1. 주문 시 손님의 커리 선택을 확인한다.
2. 각 커리를 개별 냄비에서 1인분 기준으로 조리한다.
3. 난을 새로 구워 따뜻하게 준비한다.
4. 밥, 커리, 샐러드, 더히를 세트 트레이 또는 세트 그릇에 함께 담아 제공한다.

## 가니쉬

트레이 또는 탈리에 커리, 밥, 난, 더히, 샐러드를 섹션별로 보기 좋게 배치.
