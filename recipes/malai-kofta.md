## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 감자 | 35g | 삶아서 으깨기 |
| 2 | 캐슈넛 | 5g |  |
| 3 | 중2등급 밀가루 | 5g | 코프타 반죽 |
| 4 | 토마토 | 5g |  |
| 5 | 설탕 | 20g |  |
| 6 | 데어리쿠킹크림 | 20g |  |
| 7 | ASEEL PURE GHEE | 5g |  |
| 8 | 꽃소금 | 15g |  |
| 9 | 커리 그레이비 소스 | 135g |  |
| 10 | 식용유 | 적당량 | 튀김용 |

## 조리 방법

1. 으깬 감자에 캐슈넛, 밀가루, 소금을 넣어 코프타(완자) 반죽을 만든다.
2. 탁구공 크기로 동그랗게 빚어 170°C 기름에서 황금빛이 될 때까지 튀긴다.
3. 팬에 ASEEL GHEE를 녹이고 커리 그레이비 소스, 설탕을 넣어 끓인다.
4. 데어리쿠킹크림을 넣어 크리미한 소스를 만들고 소금으로 간한다.
5. 그릇에 소스를 담고 코프타를 올려 서빙한다. 코프타는 서빙 직전에 소스에 넣을 것.

## 가니쉬

코프타 위에 생크림,생강 채와 고수잎을 사이사이에 올린다.
