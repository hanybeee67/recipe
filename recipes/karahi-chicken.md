## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭가슴살 (정육) | 70g | 깍뚝썰기 |
| 2 | 커리 그레이비 소스 | 120g |  |
| 3 | 청피망 | 30g | 채 썰기 |
| 4 | 토마토 | 15g | 웨지 컷 |
| 5 | 베트남 건고추 | 10g |  |
| 6 | CUMIN SEED WHOLE | 15g |  |
| 7 | CORRIANDER WHOLE | 10g |  |
| 8 | 베트남 고추가루 | 10g |  |
| 9 | 데어리쿠킹크림 | 10g |  |
| 10 | 꽃소금 | 5g |  |

## 조리 방법

1. 달군 팬(카라히 냄비)에 기름을 두르고 커민씨드와 코리앤더 홀을 볶아 향을 낸다.
2. 닭가슴살을 넣어 센불로 겉면을 노릇하게 볶는다.
3. 청피망, 베트남 건고추를 넣어 2분간 함께 볶는다.
4. 커리 그레이비 소스와 고추가루를 넣고 잘 섞어 중불로 2분간 조린다.
5. 소금으로 간한 후 데어리쿠킹크림을 넣어 마무리한다.
6. 냄비에 담아 뜨겁게 서빙한다.

## 가니쉬

고수잎을 중앙에 얹는다. 생강 채로 장식.
