## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 해물 모듬 (새우, 오징어, 홍합 등) | 70g | 해동 후 물기 제거 |
| 2 | 커리 그레이비 소스 | 135g |  |
| 3 | 베트남 고추가루 | 10g |  |
| 4 | 청양고추 | 15g |  |
| 5 | 데어리쿠킹크림 | 5g |  |
| 6 | 꽃소금 | 10g |  |
| 7 | 환만식초 | 5g | 빈달루 특성 |

## 조리 방법

1. 해물 모듬을 소금, 강황으로 밑간하고 팬에서 센불로 빠르게 볶아낸다.
2. 커리 그레이비 소스, 고추가루, 환만식초를 넣어 중불로 끓인다.
3. 볶은 해산물을 넣고 2-3분간 조린다.
4. 소금으로 간한다.
5. 고수잎을 올려 서빙한다.

## 가니쉬

해산물이 보이도록 완성된 커리 위에 고수잎 장식.
