## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 요거트(더히) | 200g |  |
| 2 | 오이 | 30g | 곱게 다지기 |
| 3 | 고수잎 | 5g | 다지기 |
| 4 | CUMIN powder | 2g |  |
| 5 | 베트남 고추가루 | 1g |  |
| 6 | 꽃소금 | 2g |  |
| 7 | 체리알 | 2g | 장식용 |

## 조리 방법

1. 요거트를 거품기로 부드럽게 풀어준다.
2. 곱게 다진 오이와 고수잎을 넣어 섞는다.
3. 커민가루, 고추가루, 소금을 넣어 간을 맞춘다.
4. 냉장 보관 후 차게 서빙한다.
5. 체리과 고수잎으로 장식하여 커리와 함께 제공한다.

## 가니쉬

구리 그릇에 담고 고수잎과 고추가루, 체리 1개로 마무리.
