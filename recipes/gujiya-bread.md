## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 중2등급 밀가루 | 160g |  |
| 2 | 감자 | 30g | 삶아서 으깨기 |
| 3 | 캐슈넛 | 10g | 다지기 |
| 4 | 청포도 | 10g | 반으로 자르기 |
| 5 | ASEEL PURE GHEE | 5g |  |
| 6 | 설탕 | 5g |  |
| 7 | 꽃소금 | 5g |  |
| 8 | 더히 | 30g |  |

## 조리 방법

1. 밀가루, 소금, ASEEL GHEE를 섞어 반죽하고 20분 휴지시킨다.
2. 으깬 감자에 다진 캐슈넛, 청포도, 설탕을 넣어 달콤한 소를 만든다.
3. 반죽을 반달 모양으로 밀어 소를 가운데 올리고 반으로 접어 가장자리를 주름지게 봉한다.
4. 170°C 기름에서 황금빛 갈색이 될 때까지 3~4분간 튀긴다.
5. 따뜻하게 또는 상온으로 서빙한다.

## 가니쉬

접시에 가지런히 올리고 더히를 올린다.
