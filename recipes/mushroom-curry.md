## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 새송이 버섯 | 70g | 두께 1cm로 슬라이스 |
| 2 | 커리 그레이비 소스 | 140g |  |
| 3 | 양파 | 15g | 다지기 |
| 4 | 토마토 | 5g |  |
| 5 | 데어리쿠킹크림 | 5g |  |
| 6 | 꽃소금 | 10g |  |

## 조리 방법

1. 팬에 기름을 두르고 다진 양파를 황금빛이 될 때까지 볶는다.
2. 버섯을 넣어 수분이 날아갈 때까지 센불로 볶는다.
3. 커리 그레이비 소스를 넣어 잘 섞고 중불로 3~4분간 조린다.
4. 소금으로 간하고 데어리쿠킹크림을 넣어 마무리한다.
5. 따뜻하게 서빙한다.

## 가니쉬

완성된 커리 위에 생크림 고수잎과 생강 채 장식.
