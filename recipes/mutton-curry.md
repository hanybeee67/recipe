## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 양사태살 | 40g | 깍뚝썰기 |
| 2 | 커리 그레이비 소스 | 160g | 사전 조리된 베이스 |
| 3 | 토마토홀 | 10g | 으깨기 |
| 4 | 데어리쿠킹크림 | 25g |  |
| 5 | 고수잎 | 2g | 장식용 |
| 6 | 꽃소금 | 5g |  |
| 7 | 식용유 | 10g |  |

## 조리 방법

1. 준비된 양사태살을 사용한다.
2. 커리 그레이비 소스와 으깬 토마토를 넣고 잘 섞는다.
3. 커리 그레이비 소스를 넣고 3~4분간 조린다.
4. 고기가 포크로 쉽게 찢어질 정도로 부드러워지면 크림을 넣어 마무리한다.
5. 소금으로 간하고 고수잎을 올려 서빙한다.

## 가니쉬

완성된 커리 위에 생크림. 생강 채, 고수잎으로 장식.
