## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 메인 커리 (치킨/머턴/베지) | 3개 | 선택 |
| 2 | 탄두리 요리 (티카 또는 케밥) | 1인분 |  |
| 3 | 플레인 난 또는 버터 난 | 3개 | 선택 |
| 4 | 밥 | 3인분 |  |
| 5 | 샐러드 | 1개 |  |
| 6 | 디저트 (굴랍자문 또는 라스굴라) | 1개 |  |
| 7 | 더히 | 1개 |  |

## 조리 방법

1. 손님의 커리 3종, 탄두리 선택, 난 선택, 디저트 선택을 확인한다.
2. 탄두리 요리를 먼저 마리네이드하여 준비한다.
3. 커리 3종을 조리하고 탄두리 요리를 굽는다.
4. 스타터(탄두리)를 먼저 제공하고 메인 커리와 밥, 난을 서빙한다.
5. 마지막에 디저트와 더히를 제공한다.

## 가니쉬

탄두리를 중앙에, 커리와 밥을 주변에 배치. 디저트는 별도 접시로 마무리.
