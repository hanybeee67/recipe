## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 냉동 믹스 야채 | 70g |  |
| 2 | 데어리쿠킹크림 | 20g |  |
| 3 | 커리 그레이비 소스 | 145g |  |
| 4 | 캐슈넛 | 5g | 갈아서 페이스트 |
| 5 | 꽃소금 | 5g |  |

## 조리 방법

1. 냉동 믹스 야채를 해동하고 물기를 제거한다.
2. 팬에 베이비 커리 소스와 캐슈넛 페이스트를 넣어 중불로 가열한다.
3. 믹스 야채를 넣고 약불로 3~4분간 조린다.
4. 데어리쿠킹크림을 넣어 풍부한 크림 소스로 완성한다.
5. 소금으로 간하고 캐슈넛을 올려 장식하여 서빙한다.

## 가니쉬

완성된 커리 위에 생크림, 색깔 파프리카 조각과 고수잎으로 화려하게 장식.
