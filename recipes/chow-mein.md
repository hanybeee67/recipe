## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭가슴살 (정육) | 30g | 채 썰기 |
| 2 | 스파게티 면 (삶은 것) | 100g |  |
| 3 | 양파 | 30g | 채 썰기 |
| 4 | 청피망 | 30g | 채 썰기 |
| 5 | 양배추 | 50g | 채 썰기 |
| 6 | 쪽파 | 5g |  |
| 7 | 고운 고추가루 | 10g |  |
| 8 | 베트남 건고추 | 10g |  |
| 9 | 꽃소금 | 5g |  |
| 10 | 간장 | 5g | 소스용 |

## 조리 방법

1. 스파게티 면을 소금 넣은 끓는 물에 7분간 삶은 후 물기를 빼고 식용유를 약간 버무린다.
2. 팬에 기름을 두르고 채 썬 닭가슴살을 먼저 볶아낸다.
3. 양파, 청피망, 양배추, 건고추를 넣어 센불로 2~3분간 빠르게 볶는다.
4. 고추가루, 소금을 넣어 볶다가 간장을 넣고 삶은 면을 추가한다.
5. 모든 재료가 골고루 섞이도록 센불로 2-3분간 볶는다.
6. 쪽파를 올려 서빙한다.

## 가니쉬

면 위에 쪽파 어슷썰기와 고수잎으로 마무리.
