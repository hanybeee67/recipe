## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | DAL CHANA (SUNNY) | 1,000g |  |
| 2 | 토마토 | 200g |  |
| 3 | 통마늘 | 100g |  |
| 4 | ASEEL PURE GHEE | 50g |  |
| 5 | 꽃소금 | 50g |  |
| 6 | CUMIN seed powder | 50g |  |
| 7 | 치킨마살라 파우더 | 50g |  |
| 8 | 머튼마살라 파우더 | 50g |  |
| 9 | TURMERIC POWDER | 50g |  |

## 조리 방법

1. DAL CHANA를 씻어 넉넉한 물에 담가 하룻밤(8시간 이상) 불린다.
2. 불린 콩을 새 물에 넣고 무를 때까지 40~60분간 삶는다. 손가락으로 눌러 으깨지면 된 것이다. 삶은 물은 버리지 않는다.
3. 토마토를 굵게 다지고 통마늘을 다진다.
4. 팬에 ASEEL PURE GHEE를 녹이고 다진 마늘을 볶아 향을 낸다.
5. 커민 파우더, TURMERIC POWDER, 치킨·머턴 마살라 파우더를 넣고 30초간 볶는다.
6. 다진 토마토를 넣고 뭉개질 때까지 볶는다.
7. 삶은 콩을 삶은 물과 함께 넣고 약불에서 30~40분간 뭉근히 끓인다. 주걱 뒷면으로 콩을 살짝 으깨 농도를 낸다.
8. 꽃소금으로 간을 맞춘다.
9. 식혀서 냉장 보관하고 2~3일 안에 쓴다.
