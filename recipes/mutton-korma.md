## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 양사태살 | 40g | 깍뚝썰기 |
| 2 | 커리 그레이비 소스 | 165g |  |
| 3 | 데어리쿠킹크림 | 25g |  |
| 4 | 캐슈넛 페이스트 | 10g |  |
| 5 | ASEEL PURE GHEE | 5g |  |
| 6 | 꽃소금 | 5g |  |

## 조리 방법

1. ASEEL GHEE를 팬에 녹이고 양사태살을 넣어 중불로 갈색이 되도록 볶는다.
2. 캐슈넛 페이스트를 넣어 1분간 함께 볶아 고소한 향을 낸다.
3. 커리 그레이비 소스를 붓고 물 80ml를 넣어 약불로 3~4분간 조린다.
4. 소금으로 간하고 마지막에 데어리쿠킹크림을 넣어 부드러운 크림 소스로 완성한다.

## 가니쉬

완성된 커리 위에 생크림 방울 3~4개. 고수잎 장식으로 크리미함 강조.
