## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 계란 | 85g | 완숙으로 삶기 |
| 2 | 커리 그레이비 소스 | 125g |  |
| 3 | 고수잎 | 2g | 장식 |
| 4 | 토마토홀 | 10g |  |
| 5 | 데어리쿠킹크림 | 20g |  |
| 6 | 통생강 | 5g | 채 썰기 |
| 7 | 꽃소금 | 5g |  |

## 조리 방법

1. 계란을 찬물에서 시작하여 8분간 완숙으로 삶은 후 껍질을 벗긴다.
2. 삶은 계란에 칼집을 2~3군데 내거나 반으로 잘라둔다.
3. 팬에 커리 그레이비 소스와 으깬 토마토홀을 넣어 중불로 끓인다.
4. 계란을 넣고 약불로 3~4분간 소스가 계란에 배도록 조린다.
5. 데어리쿠킹크림, 생강 채를 넣어 마무리하고 소금으로 간한다.
6. 고수잎으로 장식하여 서빙한다.

## 가니쉬

완성된 커리 위에 생크림 스파이럴. 고수잎과 생강 채로 장식. 삶은 계란 반쪽을 완성된 커리 위에 올려 단면 노출.
