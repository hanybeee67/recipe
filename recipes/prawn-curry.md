## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 찐새우살 | 45g | 해동 후 물기 제거 |
| 2 | 커리 그레이비 소스 | 170g |  |
| 3 | 토마토 | 10g | 다지기 |
| 4 | 데어리쿠킹크림 | 10g |  |
| 5 | 꽃소금 | 10g |  |
| 6 | 기 | 10g |  |

## 조리 방법

1. 팬에 기을 두르고 새우살과 토마토를 넣어 센불로 1~2분간 빠르게 볶아 향을 낸다.
2. 볶은 새우를 소스에 넣고 약불로 3~4분간 조린다.
3. 데어리쿠킹크림으로 농도를 조절하고 소금으로 간한다.
4. 고수잎으로 장식하여 밥 또는 난과 함께 서빙한다.

## 가니쉬

완성된 커리 위에 생크림. 고수잎을 띄운다..
