## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 양파 | 1,000g |  |
| 2 | 캐슈넛 | 20g |  |
| 3 | 멀균우유 | 300g |  |
| 4 | 코코넛 파우더 | 30g |  |
| 5 | 설탕 | 100g |  |
| 6 | 꽃소금 | 200g |  |

## 조리 방법

1. 양파를 굵게 썬다.
2. 캐슈넛을 따뜻한 물에 20~30분간 불린다.
3. 솥에 물을 자작하게 붓고 양파를 넣어 무를 때까지 15~20분간 삶는다. 볶지 않고 삶는 이유는 색을 내지 않기 위해서다.
4. 삶은 양파와 불린 캐슈넛을 블렌더에 넣고 곱게 간다.
5. 솥에 옮겨 중약불로 끓이며 코코넛 파우더를 넣고 덩어리 없이 풀어준다.
6. 멸균우유를 넣어 농도를 맞추고 5~10분 더 끓인다. 바닥이 눌어붙기 쉬우니 계속 젓는다.
7. 설탕과 꽃소금으로 간을 맞춘다.
8. 식혀서 냉장 보관하고 2~3일 안에 쓴다.
