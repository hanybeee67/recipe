## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 고운 고추가루 | 200g |  |
| 2 | 요거트 | 1,000g |  |
| 3 | 치킨마살라 파우더 | 100g |  |
| 4 | 머튼마살라 파우더 | 100g |  |
| 5 | CUMIN seed powder | 100g |  |
| 6 | CHAAT MASALA (MEHRAN) | 50g |  |
| 7 | 통마늘 | 200g |  |
| 8 | 통생강 | 200g |  |
| 9 | 환만식초 | 25g |  |
| 10 | 식용류 | 20g |  |
| 11 | 설탕 | 50g |  |

## 조리 방법

1. 통마늘과 통생강을 갈아 페이스트로 만든다.
2. 큰 볼에 요거트를 넣고 거품기로 부드럽게 풀어준다.
3. 고운 고추가루, 치킨·머턴 마살라 파우더, 커민 파우더, CHAAT MASALA를 넣고 덩어리가 지지 않게 잘 섞는다.
4. 마늘생강 페이스트, 환만식초, 설탕을 넣어 섞는다.
5. 식용유를 넣고 고르게 유화되도록 저어 마무리한다.
6. 밀폐 용기에 담아 냉장 보관한다. 냉장 3일. 고기에 바를 때는 필요한 만큼만 덜어 쓰고, 쓰던 소스를 통에 되돌리지 않는다.
