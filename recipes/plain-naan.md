## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 중2등급 밀가루 | 100g |  |
| 2 | 멸균우유 | 30g | 미지근하게 |
| 3 | 계란 | 10g |  |
| 4 | 설탕 | 5g |  |
| 5 | 꽃소금 | 5g |  |
| 6 | 베이킹 파우더 | 3g | 선택사항 |
| 7 | 식용유 | 5g |  |

## 조리 방법

1. 밀가루, 소금, 설탕을 섞는다. 우유, 계란, 식용유를 넣어 부드러운 반죽을 만든다.
2. 반죽을 10분간 치대어 탄력을 준 후 따뜻한 곳에서 30분 이상 발효시킨다.
3. 반죽을 탁구공 크기로 나눠 밀대로 타원형으로 밀어준다.
4. 탄두리 오븐 또는 팬을 최고 온도로 달궈 반죽을 붙이거나 올려 90초~2분간 굽는다.
5. 기포가 생기고 표면이 노릇해지면 완성.

## 가니쉬

바구니에 차곡차곡 담는다.
