## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 스파게티 면 (삶은 것) | 100g |  |
| 2 | 양파 | 30g | 채 썰기 |
| 3 | 청피망 | 30g | 채 썰기 |
| 4 | 양배추 | 50g | 채 썰기 |
| 5 | 쪽파 | 5g |  |
| 6 | 고운 고추가루 | 10g |  |
| 7 | 베트남 건고추 | 10g |  |
| 8 | 꽃소금 | 5g |  |
| 9 | 커리 그레이비 소스 | 50g |  |

## 조리 방법

1. 스파게티 면을 삶아 물기를 빼고 식용유를 버무린다.
2. 팬에 기름을 두르고 양파, 청피망, 양배추를 센불로 2~3분간 볶는다.
3. 건고추와 고추가루를 넣어 향을 낸다.
4. 커리 소스와 소금을 넣고 삶은 면을 추가하여 골고루 볶는다.
5. 쪽파를 올려 서빙한다.

## 가니쉬

면 위에 쪽파 어슷썰기와 고수잎으로 마무리.
