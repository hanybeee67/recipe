## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭 (부위 정육) | 250g | 한 입 크기로 자르기 |
| 2 | 탄두리 소스 | 30g | 마리네이드용 |
| 3 | 치킨 마살라 파우더 | 5g |  |
| 4 | CUMIN powder | 5g |  |
| 5 | 베트남 고추가루 | 5g |  |
| 6 | 꽃소금 | 5g |  |
| 7 | 식용유 | 5g |  |
| 8 | 레몬 | 10g | 서빙용 |
| 9 | 탄두리 샐라드 | 30g | 마리네이드용 |

## 조리 방법

1. 닭 조각에 탄두리 소스, 치킨 마살라 파우더, 커민가루, 고추가루, 소금을 넣어 최소 2시간 (권장 하룻밤) 마리네이드한다.
2. 탄두리 오븐을 최고 온도로 달군다.
3. 재운 닭을 꼬치에 꿰어 탄두리 오븐에서 12~15분간 굽는다.
4. 중간에 한 번 뒤집고 식용유를 바른다.
5. 바삭한 겉면과 붉은 색이 나오면 완성. 레몬즙을 뿌리고 서빙한다.

## 가니쉬

케밥을 접시에 원형 배치. 탄두리샐러드 가운데 위치.
