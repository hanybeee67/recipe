## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 양사태살 | 40g | 깍뚝썰기 |
| 2 | CHAAT MASALA | 20g | 네팔식 피클 향신료 |
| 3 | 양파 | 10g | 얇게 썰기 |
| 4 | 청양고추 | 5g |  |
| 5 | 꽃소금 | 15g |  |
| 6 | 환만식초 | 5g |  |
| 7 | 커리 그레이비 소스 | 160g |  |

## 조리 방법

1. 미리 삶아 준비된 양사태살을 사용한다.
2. 삶은 양고기를 꺼내 CHAAT MASALA, 환만식초, 소금으로 버무려 아차르(피클) 양념을 만든다.
3. 팬에 기름을 두르고 얇게 썬 양파와 청양고추를 볶아 향을 낸다.
4. 커리 그레이비 소스를 넣고 양념한 양고기를 넣어 3~4분간 볶는다.
5. 소금과 CHAAT MASALA로 최종 간을 맞추고 서빙한다.

## 가니쉬

아차르 완성된 커리 위에 양파 링과 고수잎으로 장식. 생강 채 .
