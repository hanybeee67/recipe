## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 달머커니 소스 | 190g | 렌즈콩 베이스 |
| 2 | 데어리쿠킹크림 | 15g |  |
| 3 | 통생강 | 20g | 채 썰기 |
| 4 | 통마늘 | 10g | 다지기 |
| 5 | 강황가루 | 2g |  |
| 6 | 커민씨드 | 3g |  |
| 7 | 꽃소금 | 10g |  |

## 조리 방법

1. 냄비에 달머커니 소스를 넣어 중불로 가열한다.
2. 소금, 강황가루를 넣어 맛을 조절하고 3~4분간 끓인다.
3. 작은 팬에 식용유와 ASEEL GHEE를 넣어 뜨겁게 달군 후 커민씨드를 튀겨 향을 낸다.
4. 다진 마늘과 생강을 넣어 30초간 볶은 후 달 소스에 붓는다 (타드카 기법).
5. 데어리쿠킹크림을 넣어 농도를 조절하고 완성한다.

## 가니쉬

달 완성된 커리 위에 생크림 드리즐. 프라이드 어니언과 고수잎. 생강 채 2줄기 교차 배치.
