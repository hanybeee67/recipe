## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 고급 밀가루 | 200g | 반죽용 |
| 2 | 정육 (닭) | 100g | 다지기 |
| 3 | 토마토 | 30g | 아차르 소스용 |
| 4 | 양파 | 20g |  |
| 5 | CUMIN powder | 10g |  |
| 6 | 치킨 마살라 파우더 | 10g |  |
| 7 | 베트남 고추가루 | 10g | 얼큰한 맛 |
| 8 | 꽃소금 | 10g |  |
| 9 | 고수잎 | 10g |  |

## 조리 방법

1. 기본 모모와 동일한 방법으로 모모를 만들어 쪄낸다.
2. 토마토를 달궈진 팬에 직화로 구워 껍질을 벗긴 후 으깬다.
3. 으깬 토마토에 베트남 고추가루, CUMIN, 고수잎, 소금을 넣어 아차르 수프 소스를 만든다.
4. 물 200ml를 추가하여 걸쭉한 수프 농도가 되도록 끓인다.
5. 그릇에 찐 모모를 담고 따뜻한 아차르 수프를 부어 서빙한다.

## 가니쉬

수프에 모모를 넣고 쪽파 어슷썰기와 고수잎으로 상단 장식.
