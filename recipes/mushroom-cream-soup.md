## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 크림스프 파우더 | 17g |  |
| 2 | 새송이 버섯 | 30g | 잘게 다지기 |
| 3 | 물 또는 채소 육수 | 250ml |  |
| 4 | 꽃소금 | 3g |  |
| 5 | 흑후추가루 | 1g |  |

## 조리 방법

1. 버섯을 잘게 다져 팬에서 기름 없이 볶아 수분을 날린다.
2. 냄비에 물 250ml를 끓이고 크림스프 파우더를 찬물에 풀어 넣는다.
3. 볶은 버섯을 넣어 5분간 함께 끓인다.
4. 소금, 후추로 간하고 따뜻하게 서빙한다.

## 가니쉬

컵 위에 버섯 슬라이스 1~2조각 올리고 흑후추로 마무리.
