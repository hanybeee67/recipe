## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 냉동 믹스 야채 | 85g |  |
| 2 | 커리 그레이비 소스 | 140g |  |
| 3 | 토마토 | 5g | 다지기 |
| 4 | 데어리쿠킹크림 | 5g |  |
| 5 | 꽃소금 | 10g |  |

## 조리 방법

1. 냉동 믹스 야채를 찬물에 해동 후 물기를 빼둔다.
2. 팬에 커리 그레이비 소스와 다진 토마토를 넣어 중불로 3분간 끓인다.
3. 믹스 야채를 넣고 잘 섞어 중약불로 3~4분간 조린다.
4. 소금으로 간하고 데어리쿠킹크림을 넣어 마무리한다.
5. 고수잎으로 장식하여 서빙한다.

## 가니쉬

완성된 커리 위에 생크림. 고수잎과 생강 채로 장식.
