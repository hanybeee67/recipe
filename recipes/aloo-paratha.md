## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 중2등급 밀가루 | 160g |  |
| 2 | 감자 | 30g | 삶아서 으깨기 |
| 3 | 양파 | 10g | 다지기 |
| 4 | CHAAT MASALA | 5g |  |
| 5 | ASEEL PURE GHEE | 10g |  |
| 6 | 청양고추 | 5g | 다지기 |
| 7 | 꽃소금 | 5g |  |
| 8 | 더히 | 20g |  |

## 조리 방법

1. 밀가루, 소금, 물로 단단한 반죽을 만들어 30분 휴지시킨다.
2. 으깬 감자에 다진 양파, 청양고추, CHAAT MASALA, 소금을 넣어 소를 만든다.
3. 반죽을 동그랗게 밀어 감자 소를 가운데 넣고 봉한 후 다시 밀어 얇게 편다.
4. 기름을 두른 달군 팬에서 양면을 노릇하게 2~3분씩 굽는다.
5. ASEEL GHEE를 바르고 따뜻할 때 더히와 함께 서빙한다.

## 가니쉬

반으로 잘라 접시에 세워 배치. 더히 곁들임.
