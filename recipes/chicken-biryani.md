## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭 (부위 정육) | 200g | 마리네이드용 |
| 2 | 바스마티 쌀 | 200g | 씻어서 30분 불리기 |
| 3 | 양파 | 50g | 캐러멜라이즈 |
| 4 | 요거트 | 50g | 마리네이드 |
| 5 | 치킨 마살라 파우더 | 15g |  |
| 6 | 사프란 | 1g | 따뜻한 물에 우리기 |
| 7 | ASEEL PURE GHEE | 20g |  |
| 8 | 꽃소금 | 10g |  |
| 9 | 고수잎· | 5g |  |
| 10 | 식용유 | 20g |  |

## 조리 방법

1. 닭을 요거트, 치킨 마살라, 소금으로 최소 1시간 마리네이드한다.
2. 냄비에 기름과 GHEE를 두르고 슬라이스한 양파를 황금빛 갈색이 될 때까지 캐러멜라이즈한다.
3. 마리네이드한 닭을 넣어 센불로 5분간 볶는다.
4. 불린 바스마티 쌀을 닭 위에 층층이 쌓고 사프란 물을 골고루 뿌린다.
5. 고수잎, 캐러멜라이즈한 양파를 올리고 뚜껑을 꼭 덮어 약불에서 20~25분간 dum(증기) 조리한다.
6. 뚜껑을 열고 살살 섞어 접시에 담아 요거트와 함께 서빙한다.

## 가니쉬

원형 틀로 눌러 하트 또는 원형 모양으로 담는다. 프라이드 어니언과 체리 1개, 고수잎으로 상단 장식.
