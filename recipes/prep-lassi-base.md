## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 달럽프라이드 | 200g |  |
| 2 | 요거트 | 1,000g |  |
| 3 | 설탕 | 200g |  |
| 4 | 물 | 800g |  |

## 조리 방법

1. 큰 볼에 요거트를 넣고 거품기로 덩어리 없이 푼다.
2. 설탕을 넣어 완전히 녹인다.
3. 달럽프라이드를 넣고 고르게 섞는다.
4. 물을 조금씩 부으며 저어 원하는 농도로 맞춘다.
5. 냉장 보관하고 당일에 쓴다. 주문이 들어오면 이 베이스에 과일 퓨레를 더해 블렌딩한다.
