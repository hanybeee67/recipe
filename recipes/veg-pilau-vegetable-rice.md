## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 바스마티 쌀 | 200g | 불리기 |
| 2 | 냉동 믹스 야채 | 100g |  |
| 3 | 양파 | 30g | 다지기 |
| 4 | ASEEL PURE GHEE | 10g |  |
| 5 | 코코넛 파우더 | 5g |  |
| 6 | 설탕 | 2g |  |
| 7 | 꽃소금 | 5g |  |

## 조리 방법

1. 바스마티 라이스를 준비한다.
2. 냄비에 ASEEL GHEE를 두르고 다진 양파를 황금빛이 될 때까지 볶는다.
3. 냉동 믹스 야채를 넣어 2분간 볶는다.
4. 바스마티 라이스를 넣어 1분간 함께 볶는다.
5. 코코넛 파우더를 넣은 후 다시 1분정도 볶아준다.
6. 살살 섞어 그릇에 담아 서빙한다.

## 가니쉬

둥근 돔 모양으로 담고 색깔 야채 조각이 위에 보이도록 마무리.
