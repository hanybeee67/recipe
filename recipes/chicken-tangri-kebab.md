## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭 (닭다리) | 300g | 드럼스틱 또는 큰 조각 |
| 2 | 레몬 | 10g | 마리네이드 |
| 3 | CUMIN powder | 5g |  |
| 4 | 치킨 마살라 파우더 | 5g |  |
| 5 | 베트남 고추가루 | 10g |  |
| 6 | 꽃소금 | 5g |  |
| 7 | 식용유 | 5g |  |
| 8 | 청양고추 | 30g | 서빙용 |

## 조리 방법

1. 닭 (드럼스틱)에 깊은 칼집을 내어 향신료가 잘 배도록 한다.
2. 마살라, 커민, 고추가루, 소금을 넣어 최소 4시간 마리네이드한다.
3. 탄두리 오븐에서 180°C로 18~22분간 굽는다.
4. 중간에 식용유를 바르며 전체적으로 고루 굽는다.
5. ,오이,당근, 레몬과 함께 서빙한다.

## 가니쉬

뼈 끝에 호일 마감. 접시 중앙에 레몬 웨지.
