## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 감자 | 65g | 깍뚝썰기 |
| 2 | 냉동 콜리플라워 | 65g | 먹기 좋게 자르기 |
| 3 | 커리 그레이비 소스 | 100g |  |
| 4 | 데어리쿠킹크림 | 5g |  |
| 5 | 꽃소금 | 10g |  |
| 6 | 강황가루 | 2g |  |

## 조리 방법

1. 감자와 콜리플라워를 소금물에 3~4분간 데쳐 반만 익힌다.
2. 팬에 기름을 두르고 강황가루를 넣어 1분간 향을 낸 후 데친 채소를 넣어 볶는다.
3. 커리 그레이비 소스를 넣고 잘 섞어 약불로 3~4분간 조린다.
4. 채소가 완전히 익으면 소금으로 간하고 데어리쿠킹크림을 넣어 마무리한다.
5. 고수잎으로 장식하여 서빙한다.

## 가니쉬

완성된 커리 위에 고수잎을 올리고 생강 채 장식. 강황 색이 선명하게 보이도록 마무리.
