## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭가슴살 (정육) | 60g | 깍뚝썰기 |
| 2 | 커리 그레이비 소스 | 120g |  |
| 3 | 캐슈넛 | 5g |  |
| 4 | 계란 | 5g | 삶아서 반으로 자르기 |
| 5 | 설탕 | 20g |  |
| 6 | 꽃소금 | 15g |  |
| 7 | 데어리쿠킹크림 | 20g |  |
| 8 | ASEEL PURE GHEE | 5g |  |

## 조리 방법

1. ASEEL GHEE를 팬에 녹이고 캐슈넛을 황금빛이 될 때까지 볶아 꺼낸다.
2. 같은 팬에 삶은 닭가슴살을 다져 넣어 겉면을 노릇하게 볶는다.
3. 커리 그레이비 소스, 설탕을 넣어 잘 섞는다.
4. 약불로 3~4분간 조린 후 크림을 넣어 2분 더 익힌다.
5. 볶은 캐슈넛을 올리고 데어리쿠킹크림으로 마무리한다. 소금으로 간한다.

## 가니쉬

볶은 캐슈넛을 완성된 커리 위에 뿌리고 생크림. 고수잎 및 체리 1알으로 마무리.
