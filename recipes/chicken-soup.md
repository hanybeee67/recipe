## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 크림스프 파우더 | 17g |  |
| 2 | 닭가슴살 (정육) | 20g | 잘게 다지기 |
| 3 | 물 또는 닭 육수 | 250ml |  |
| 4 | 꽃소금 | 3g |  |
| 5 | 흑후추가루 | 1g |  |

## 조리 방법

1. 냄비에 물 250ml를 넣고 끓인다.
2. 크림스프 파우더를 찬물 50ml에 풀어 덩어리 없이 용해시킨다.
3. 끓는 물에 풀어놓은 크림스프를 넣어 계속 저으며 3분간 끓인다.
4. 잘게 다진 닭가슴살을 넣어 완전히 익을 때까지 3~5분 더 끓인다.
5. 소금과 후추로 간하고 따뜻한 컵에 담아 서빙한다.

## 가니쉬

컵 위에 흑후추를 한 번 갈아 뿌린다. 크루통 3~4개 올리거나 파슬리 1꼬집.
