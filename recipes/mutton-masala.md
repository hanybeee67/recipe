## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 양사태살 | 40g | 깍뚝썰기 |
| 2 | 커리 그레이비 소스 | 150g |  |
| 3 | 청양고추 | 15g | 어슷썰기 |
| 4 | 토마토 | 10g | 다지기 |
| 5 | 완두콩 | 10g |  |
| 6 | 데어리쿠킹크림 | 20g |  |
| 7 | 꽃소금 | 5g |  |

## 조리 방법

1. 준비된 양사태살을 사용한다.
2. 팬에 기름을 두르고 청양고추, 다진 토마토를 볶아 향을 낸다.
3. 커리 그레이비 소스를 넣고 물 80ml 추가 후 중불로 3~4분간 조린다.
4. 완두콩을 넣고 5분 더 익힌 후 크림으로 마무리한다.
5. 소금으로 간하고 고수잎으로 장식하여 서빙한다.

## 가니쉬

완성된 커리 위에 생크림. 생강 채와 고수잎 장식.
