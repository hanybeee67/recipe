## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 찐새우살 | 40g | 해동 후 물기 제거 |
| 2 | 커리 그레이비 소스 | 160g |  |
| 3 | 토마토 | 10g | 다지기 |
| 4 | 베트남 고추가루 | 10g |  |
| 5 | 청양고추 | 15g | 어슷썰기 |
| 6 | 데어리쿠킹크림 | 10g |  |
| 7 | 꽃소금 | 10g |  |
| 8 | 양파 | 10g |  |

## 조리 방법

1. 팬에 기를 두르고 청양고추를 볶아 향을 낸다.
2. 새우살을 넣어 센불로 1~2분 빠르게 볶는다.
3. 커리 그레이비 소스, 다진 토마토, 베트남 고추가루, 양파를 넣어 중불로 끓인다.
4. 약불로 2-3분간 조린다.
5. 소금으로 간하고 완성한다.

## 가니쉬

청양고추 슬라이스를 완성된 커리 위에 올려 칠리 메뉴 강조.
