## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 중2등급 밀가루 | 160g |  |
| 2 | 허니 (꿀) | 20g | 반죽 및 마무리용 |
| 3 | 멸균우유 | 30g |  |
| 4 | 계란 | 10g |  |
| 5 | 설탕 | 5g |  |
| 6 | 꽃소금 | 5g |  |
| 7 | 베이킹 파우더 | 3g |  |

## 조리 방법

1. 밀가루, 소금, 설탕, 꿀 10g, 우유, 계란을 넣어 부드럽게 반죽한다.
2. 반죽을 15분간 치대고 따뜻한 곳에서 40분간 발효시킨다.
3. 반죽을 타원형으로 밀어 옥수수(열탄) 또는 참깨를 표면에 올린다.
4. 탄두리 오븐 또는 팬에서 노릇해질 때까지 굽는다.
5. 구운 후 즉시 나머지 꿀 10g을 솔로 얇게 바르고 서빙한다.

## 가니쉬

바구니에 담고 꿀을 선으로 드리즐. 버터 한 조각 올려 광택 마무리.
