## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 고수 | 500g |  |
| 2 | 통마늘 | 100g |  |
| 3 | 청양고추 | 30g |  |
| 4 | CHAAT MASALA (MEHRAN) | 10g |  |
| 5 | 꽃소금 | 10g |  |
| 6 | 환만식초 | 15g |  |
| 7 | 요거트 | 150g |  |
| 8 | 통생강 | 100g |  |

## 조리 방법

1. 고수를 씻어 물기를 털어낸다. 굵은 줄기는 잘라낸다.
2. 통마늘, 통생강, 청양고추를 굵게 썬다.
3. 고수, 마늘, 생강, 청양고추, CHAAT MASALA, 꽃소금을 블렌더에 넣고 곱게 간다. 되면 물을 조금씩 넣어 농도를 맞춘다.
4. 요거트와 환만식초를 넣고 짧게 돌려 섞는다. 오래 돌리면 요거트가 분리된다.
5. 간을 보고 소금·식초로 맞춘다.
6. 냉장 보관하고 2일 안에 쓴다.
