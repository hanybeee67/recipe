## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 중2등급 밀가루 | 100g |  |
| 2 | 멸균우유 | 30g |  |
| 3 | 계란 | 10g |  |
| 4 | ASEEL PURE GHEE | 10g |  |
| 5 | 통마늘 | 10g | 곱게 다지기 |
| 6 | 설탕 | 5g |  |
| 7 | 꽃소금 | 5g |  |
| 8 | 베이킹 파우더 | 3g |  |

## 조리 방법

1. 밀가루, 소금, 설탕을 섞고 ASEEL GHEE, 우유, 계란을 넣어 반죽한다.
2. 반죽을 15분간 치대고 40분간 발효시킨다.
3. 반죽을 밀어 곱게 다진 마늘을 표면에 고르게 올리고 가볍게 눌러준다.
4. 마늘이 붙은 면이 아래로 가도록 탄두리 오븐 또는 팬에서 굽는다.
5. 구운 후 ASEEL GHEE를 바르고 신선한 다진 마늘과 고수잎을 추가로 올려 서빙한다.

## 가니쉬

바구니에 담고 마늘향이 올라오도록 즉시 서빙.
