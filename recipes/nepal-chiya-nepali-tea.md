## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | LIPTON TEA(찌야) | 10g |  |
| 2 | 멸균우유 | 10ml |  |
| 3 | 물 | 150ml |  |
| 4 | 설탕 | 5g |  |

## 조리 방법

1. 냄비에 물을 끓이고 차 잎(LIPTON 찌야)을 넣어 3분간 강하게 끓인다.
2. 멸균우유를 넣고 2분간 더 끓여 차 색이 짙은 갈색이 되도록 한다.
3. 설탕을 넣어 단맛을 조절한다.
4. 찻잎을 걸러내고 따뜻한 컵에 담아 서빙한다.

## 가니쉬

손잡이 있는 도자기 또는 전통 구리컵에 담는다. 계피스틱 1개를 꽂아도 좋다.
