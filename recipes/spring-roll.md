## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 스프링롤 페이스트리 | 50g |  |
| 2 | 양파 | 30g | 채 썰기 |
| 3 | 양배추 | 50g | 채 썰기 |
| 4 | 청피망 | 30g | 채 썰기 |
| 5 | 스파게티 면 (삶은 것) | 100g |  |
| 6 | 쪽파 | 5g |  |
| 7 | 고운 고추가루 | 10g |  |
| 8 | 꽃소금 | 5g |  |
| 9 | 식용유 | 적당량 | 튀김용 |

## 조리 방법

1. 양파, 양배추, 청피망을 채 썰어 팬에 기름을 두르고 볶는다.
2. 삶은 스파게티 면, 쪽파, 고추가루, 소금을 넣어 골고루 볶아 소를 만들고 식힌다.
3. 스프링롤 페이스트리를 펼치고 소를 올려 단단하게 돌돌 만다. 끝부분은 물을 묻혀 봉한다.
4. 170°C 기름에서 황금색이 되도록 3~4분간 튀긴다.
5. 칠리 소스와 함께 서빙한다.

## 가니쉬

롤 4개를 사선으로 배치. 채 썬 양배추와 당근, 체리로 공간 채움.
