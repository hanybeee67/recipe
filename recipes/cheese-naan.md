## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 중2등급 밀가루 | 160g |  |
| 2 | ASEEL PURE GHEE | 5g |  |
| 3 | 모자렐라치즈 | 75g |  |
| 4 | 멸균우유 | 30g |  |
| 5 | 계란 | 10g |  |
| 6 | 꽃소금 | 5g |  |
| 7 | 설탕 | 5g |  |
| 8 | 베이킹 파우더 | 3g |  |

## 조리 방법

1. 밀가루, 소금, 설탕, ASEEL GHEE, 우유, 계란으로 반죽을 만들어 40분간 발효시킨다.
2. 반죽을 타원형으로 밀어 중앙에 분말치즈를 고르게 올린다.
3. 반죽의 가장자리를 안쪽으로 접어 치즈를 감싸고 다시 밀어 얇게 편다.
4. 치즈가 있는 면이 아래로 가도록 팬에 올려 중불로 굽는다.
5. 뒤집어 반대 면도 굽고 ASEEL GHEE를 바른 후 따뜻하게 서빙한다.

## 가니쉬

별 모양으로 잘라 원형 접시에 담고 중앙에 요거트 소스 그릇.
