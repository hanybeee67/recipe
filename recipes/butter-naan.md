## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 중2등급 밀가루 | 100g |  |
| 2 | 멸균우유 | 30g |  |
| 3 | 계란 | 10g |  |
| 4 | ASEEL PURE GHEE (버터) | 20g | 반죽 및 마무리용 |
| 5 | 설탕 | 5g |  |
| 6 | 꽃소금 | 5g |  |
| 7 | 베이킹 파우더 | 3g |  |

## 조리 방법

1. 밀가루, 소금, 설탕을 섞고 ASEEL GHEE 10g, 우유, 계란을 넣어 반죽한다.
2. 반죽을 15분간 치대고 따뜻한 곳에서 40분간 발효시킨다.
3. 반죽을 타원형으로 밀어 탄두리 오븐 또는 팬에서 굽는다.
4. 구워진 난에 즉시 나머지 ASEEL GHEE 10g을 듬뿍 바른다.
5. 따뜻할 때 서빙한다.

## 가니쉬

바구니에 담고 위에 버터를 바른다.
