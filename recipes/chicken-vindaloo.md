## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭가슴살 (정육) | 70g | 깍뚝썰기 |
| 2 | 커리 그레이비 소스 | 140g |  |
| 3 | 베트남 고추가루 | 15g |  |
| 4 | 고운 고추가루 | 10g |  |
| 5 | Clove powder (정향가루) | 5g |  |
| 6 | 꽃소금 | 15g |  |

## 조리 방법

1. 닭가슴살을 큐브형태로 잘라 준비한다.
2. 팬에 기름을 두르고 정향가루와 고추가루를 30초정도 볶는다.
3. 커리 그레이비 소스와 나머지 마리네이드를 넣어 잘 섞는다.
4. 물 80ml를 넣고 약불로 15분간 조린다.
5. 소금으로 간을 맞추고 서빙한다.

## 가니쉬

청양고추 2~3개를 완성된 커리 위에 올려 매운 메뉴임을 시각적으로 표현.
