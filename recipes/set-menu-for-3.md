## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 메인 커리 (치킨/머턴/베지) | 2개 | 선택 |
| 2 | 스타터 (사모사 또는 모모) | 1인분 |  |
| 3 | 플레인 난 | 3개 |  |
| 4 | 밥 | 3인분 |  |
| 5 | 샐러드 | 1개 |  |
| 6 | 더히 | 1개 |  |

## 조리 방법

1. 손님의 커리 2종과 스타터를 확인한다.
2. 스타터(사모사 또는 모모)를 먼저 준비하여 서빙한다.
3. 메인 커리 2종을 조리하고 난과 밥을 함께 준비한다.
4. 모든 음식을 세트로 함께 담아 서빙한다.

## 가니쉬

스타터를 먼저 예쁜 접시에 내고, 메인은 탈리 형식으로 구성.
