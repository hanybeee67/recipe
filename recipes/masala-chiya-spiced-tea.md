## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | LIPTON TEA(찌야) | 10g |  |
| 2 | 멸균우유 | 10ml |  |
| 3 | 물 | 150ml |  |
| 4 | 설탕 | 5g |  |
| 5 | 계피가루 | 5g |  |

## 조리 방법

1. 냄비에 물을 끓이고 차 잎과 계피가루를 넣어 3분간 끓인다.
2. 멸균우유를 넣고 2분간 더 끓인다.
3. 설탕으로 간을 맞춘다.
4. 찻잎을 걸러내고 컵에 담아 계피가루를 살짝 뿌려 서빙한다.

## 가니쉬

도자기 또는 전통 구리컵에 담고 계피가루를 표면에 살짝 뿌린다.
