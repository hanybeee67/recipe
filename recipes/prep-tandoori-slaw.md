## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 양배추 | 10g |  |
| 2 | 양파 | 5g |  |
| 3 | 당근 | 5g |  |
| 4 | 고운 고추가루 | 5g |  |
| 5 | 환만식초 | 5g |  |
| 6 | CHAAT MASALA (MEHRAN) | 3g |  |
| 7 | 꽃소금 | 5g |  |

## 조리 방법

1. 양배추, 양파, 당근을 아주 가늘게 채 썬다.
2. 꽃소금을 뿌려 10분간 절인 뒤 물기를 꼭 짠다. 수율 60%는 이 단계에서 나온다.
3. 고운 고추가루와 CHAAT MASALA를 넣어 고루 버무린다.
4. 환만식초를 넣어 섞고 간을 본다.
5. 냉장 보관하고 만든 당일에 쓴다. 시간이 지나면 물이 생기고 아삭함이 사라진다.
