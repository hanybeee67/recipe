## 재료

| # | 재료명 | 수량 | 비고 |
|---:|---|---|---|
| 1 | 닭 가슴살 | 75g | 깍뚝썰기 |
| 2 | 커리 그레이비 소스 | 145g |  |
| 3 | 데어리쿠킹크림 | 20g |  |
| 4 | 꽃소금 | 5g |  |
| 5 | ASEEL PURE GHEE | 5g |  |

## 조리 방법

1. ASEEL GHEE를 팬에 녹이고 닭을 넣어 중불로 겉면을 노릇하게 볶는다.
2. 커리 그레이비 소스를 넣고 잘 섞어 약불로 3~4분간 조린다.
3. 닭이 완전히 익으면 데어리쿠킹크림을 넣어 부드러운 소스로 완성한다.
4. 소금으로 간하고 따뜻하게 서빙한다.

## 가니쉬

생크림을 완성된 커리 위에 방울방울 올려 코르마 특유의 크리미함 강조. 고수잎 장식.
